# VoiceCode

[English](README.en.md) · **Русский**

Голосовая мини-копия [opencode](https://opencode.ai): зажимаешь клавишу, говоришь
по-русски, отпускаешь — и слышишь ответ. Без чата, без истории на экране, только
голос и анимированный интерфейс в стиле opencode.

![Интерфейс VoiceCode](docs/preview.png)

## Что умеет

- **Push-to-talk.** Удерживай `Space` в окне или `F8` в любой программе, говори,
  отпусти — дальше всё само.
- **Локальное распознавание.** `faster-whisper small` в int8 на CPU, модель уже
  лежит в `models/faster-whisper-small`, интернет для распознавания не нужен.
- **Голосовой ответ.** `edge-tts` (голос `ru-RU-DmitryNeural`) с потоковой
  озвучкой по предложениям; если Microsoft недоступен — системный голос Windows
  (`Microsoft Irina Desktop`) без пауз и падений.
- **Системные команды.** Открывает программы и сайты, ищет в интернете, делает
  скриншот, управляет громкостью, блокирует компьютер, сворачивает и закрывает
  окна, подсказывает время и дату — всё локально, за миллисекунды.
- **Всё остальное — в opencode.** Вопросы, код, объяснения уходят в
  `opencode-cli run`, ответ приходит потоком и сразу озвучивается.
- **Никакого текстового чата.** Только статус, одна строка распознанного текста
  и строка ответа — они исчезают сами.

## Как это работает

```
F8 / Space / кнопка
        │  (микрофон уже открыт)
        ▼
faster-whisper small → текст
        │
        ├─ локальный роутер команд → действие + короткая фраза
        │
        └─ opencode-cli run --format json → поток текста
                                              │
                                              ▼
                                   edge-tts / SAPI по предложениям
```

Ключевые решения ради скорости:

- микрофонный поток PortAudio открыт постоянно, запись начинается мгновенно;
- модель Whisper прогревается при старте, первый ответ не ждёт загрузки;
- строка ответа режется на предложения и озвучивается по мере поступления;
- локальные команды не ходят в сеть вообще;
- провайдер opencode выбирается один раз в `config.json`, без пересогласований.

Измерено на 8-ядерном CPU: распознавание ≈ 0,6–0,7 от длительности фразы
(4,4 с речи → ≈ 2,9 с), opencode ≈ 2,0–2,5 с на `deepseek-v4.1-flash-free`,
старт озвучки ≈ 0,2 с (SAPI) или ≈ 0,5–1 с (edge-tts).

## Требования

- Windows 10/11 (64-бит).
- Микрофон и динамики/наушники.
- Для сборки из исходников — Python 3.10–3.12 (проверено на 3.12).

Установщик `VoiceCode-Setup.exe` не требует Python и ничего не доустанавливает:
внутри уже лежат интерпретатор, модель Whisper и `opencode-cli.exe` v2.1.1.
OpenCode Desktop на машине не обязателен.

## Установка

### Установщик (рекомендуется)

Запусти `VoiceCode-Setup.exe`. Откроется анимированное окно установщика: он
распакует приложение в `%LOCALAPPDATA%\Programs\VoiceCode`, создаст ярлыки на
рабочем столе и в меню «Пуск», добавит запись в «Приложения и возможности»,
а затем предложит сразу запустить VoiceCode. Права администратора не нужны,
всё ставится для текущего пользователя за ~20 секунд.

При первом запуске Windows SmartScreen может предупредить, что издатель не
известен (установщик не подписан сертификатом). Нажми «Подробнее» →
«Выполнить в любом случае».

Удаление — через «Параметры → Приложения → VoiceCode» или
`%LOCALAPPDATA%\Programs\VoiceCode\uninstall.bat`.

### Из исходников

```bat
install.bat
```

Скрипт создаст `.venv`, поставит зависимости, проверит opencode, модель, голоса,
микрофоны и `pygame.mixer`. Всё, что нашлось, он печатает в консоль.

Вручную:

```bat
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe tools\warmup.py
```

Если `opencode-cli.exe` не установлен, VoiceCode ищет его рядом с собой
(`VoiceCode.exe`), затем в `PATH` и в `%LOCALAPPDATA%\Programs\@opencodedesktop\resources\`.
Положить CLI рядом с приложением — самый надёжный вариант.

### Сборка установщика

```bat
.venv\Scripts\python.exe -m pip install pyinstaller
.venv\Scripts\python.exe -m PyInstaller packaging\voicecode.spec --noconfirm
.venv\Scripts\python.exe packaging\build_installer.py
```

Результат — `dist\VoiceCode-Setup.exe` (≈420 МБ, один файл). Нужен установленный
7-Zip (`C:\Program Files\7-Zip\7z.exe`); `7za.exe` для распаковки на машине
получателя скрипт сам достаёт из официального «7-Zip Extra».

Как устроен установщик: `packaging/installer.spec` собирает PySide6-интерфейс
(анимации, прогресс, экран «Готово»), а `packaging/build_installer.py`
приклеивает к нему `payload.7z` с 16-байтным трейлером. Интерфейс читает
трейлер из собственного файла, распаковывает payload встроенным `7za.exe`
и показывает прогресс в реальном времени. Промежуточные сборки лежат в
`dist\installer-ui` и `%TEMP%\voicecode-installer` (`--reuse` переиспользует
готовый `payload.7z`, `--skip-ui` — готовый интерфейс).

## Запуск

```bat
run.bat          :: без консоли, через pythonw.exe
run-debug.bat    :: с консолью и подробным логом
```

Если модель Whisper отсутствует, `run.bat` сначала предложит выполнить
`install.bat`. Приложение закрывается в трей, `Ctrl+Q` или «Выход» в меню трея
завершают его полностью.

Проверить синтез речи на установленной копии можно так:

```bat
"%LOCALAPPDATA%\Programs\VoiceCode\VoiceCode.exe" --say "Проверка голоса"
```

## Управление

| Что | Как |
| --- | --- |
| Говорить | зажать `Space` в окне, `F8` в любом приложении или кнопку «Держи и говори» |
| Отменить ответ / остановить озвучку | `Esc`, или новая фраза, или слово «стоп» |
| Повторить последний ответ | `Ctrl+R` или «повтори» |
| Свернуть в трей | кнопка «—» или слово «скройся» |
| Выход | `Ctrl+Q`, меню трея |
| Перетащить окно | потянуть за карточку |

`F8` работает глобально через `keyboard`. Если клавиша не срабатывает в
приложениях, запущенных от администратора, запусти VoiceCode тоже от
администратора или задай другую клавишу в конфиге.

## Настройка

Все параметры лежат в `config.json` рядом с `main.py`. Файл перечитывается при
запуске, менять его лучше при закрытом приложении.

| Параметр | По умолчанию | Что делает |
| --- | --- | --- |
| `language` | `"ru"` | язык распознавания; `"auto"` — определять автоматически |
| `whisper_model` | `"models/faster-whisper-small"` | путь к локальной модели или имя модели Hugging Face (`"small"`, `"base"`, `"medium"`) |
| `whisper_compute` | `"int8"` | тип вычислений CTranslate2 (`int8`, `int8_float32`, `float32`) |
| `whisper_threads` | `0` | число потоков CPU; `0` — все ядра минус два |
| `tts_engine` | `"edge"` | `"edge"`, `"system"` (только офлайн SAPI) или `"auto"` |
| `voice` | `"ru-RU-DmitryNeural"` | голос edge-tts; другие: `ru-RU-SvetlanaNeural`, `ru-RU-DariyaNeural` |
| `tts_rate` | `"+8%"` | скорость речи edge-tts |
| `tts_volume` | `"+0%"` | громкость edge-tts |
| `opencode_cli` | `""` | путь к `opencode-cli.exe`, если автопоиск не сработал |
| `model` | `"opencode/deepseek-v4.1-flash-free"` | модель opencode |
| `agent` | `"build"` | агент opencode |
| `workspace` | `"agent"` | рабочая папка opencode (относительно проекта) |
| `auto_approve` | `false` | добавляет `--auto`, чтобы opencode не спрашивал подтверждений |
| `keep_context` | `true` | подмешивать последние реплики в запрос |
| `max_context_turns` | `6` | сколько пар «вопрос-ответ» помнить |
| `timeout_sec` | `150` | предел ожидания ответа opencode |
| `microphone` | `""` | имя микрофона; `""` — устройство по умолчанию |
| `sample_rate` | `16000` | частота записи |
| `global_hotkey` | `"f8"` | глобальная клавиша push-to-talk |
| `greeting` | `true` | здороваться голосом после загрузки |
| `minimize_to_tray` | `true` | закрытие окна сворачивает в трей |
| `search_url` | Яндекс | шаблон поиска, `{query}` подставляется |
| `show_caption` | `true` | показывать строку ответа |
| `start_minimized` | `false` | стартовать сразу в трее |

Пример: самый быстрый вариант для слабого ноутбука.

```json
{
  "whisper_model": "models/faster-whisper-small",
  "whisper_threads": 4,
  "tts_engine": "system",
  "model": "opencode/deepseek-v4.1-flash-free"
}
```

### Модель распознавания

В комплекте — `faster-whisper-small` в int8 (≈ 240 МБ). Это компромисс между
точностью на русском и скоростью на CPU.

Пересобрать модель из оригинального чекпоинта OpenAI:

```bat
.venv\Scripts\python.exe -m pip install torch --index-url https://download.pytorch.org/whl/cpu
.venv\Scripts\python.exe -m pip install transformers openai-whisper
.venv\Scripts\python.exe tools\build_model.py
```

Скрипт скачает `small.pt`, сконвертирует его в Hugging Face-формат, соберёт
токенизатор из ассетов `openai-whisper` и сожмёт модель в CTranslate2 `int8`.
Для `base` (быстрее, но менее точно): `--size base --output models\faster-whisper-base`.
Затем укажи новый путь в `whisper_model`.

Можно вообще не хранить модель локально: поставь `"whisper_model": "small"` —
faster-whisper скачает её с Hugging Face при первом запуске (нужен интернет).

### Голос

По умолчанию используется `edge-tts` — он звучит живо, но требует доступа к
`speech.platform.bing.com`. При старте VoiceCode один раз проверяет доступность
(2 с) и при неудаче сразу переключается на SAPI, чтобы не тратить время на
таймауты при каждой фразе.

Полностью офлайновый режим:

```json
{ "tts_engine": "system" }
```

SAPI возьмёт русский голос из Windows; если русского нет, установи его в
«Параметры → Время и язык → Речь».

### opencode

VoiceCode вызывает CLI в stateless-режиме:

```
opencode-cli run --format json --model <model> --agent <agent> "<промпт>"
```

Бесплатный тариф opencode не принимает `--session` и `--continue`, поэтому
контекст диалога собирается локально в промпт (`keep_context`,
`max_context_turns`). Каждый ответ приходит потоком JSON-событий и озвучивается
по мере поступления текста.

Рабочая папка — `agent\`. В `agent\AGENTS.md` описаны правила для модели: отвечать
по-русски, коротко, без markdown и кода, потому что ответ читают вслух.

Самые быстрые бесплатные модели, которые проверялись: `opencode/deepseek-v4.1-flash-free`
(≈ 2,0–2,5 с) и `opencode/big-pickle` (≈ 3,1 с). `glm-5.3-flash-free` и `mimo`
заметно медленнее, `minimax` — больше 15 с.

## Приватность

- Запись микрофона живёт только в оперативной памяти и никуда не сохраняется.
- Распознавание и локальные команды выполняются на компьютере.
- В opencode уходит только распознанный текст (и последние реплики, если
  включён `keep_context`). Куда именно — зависит от провайдера, выбранного в
  opencode.
- В `logs\voicecode.log` попадают распознанные фразы и служебные события; файл
  ротируется, его можно удалить в любой момент.

## Диагностика

```bat
.venv\Scripts\python.exe tools\warmup.py       :: проверка окружения и моделей
.venv\Scripts\python.exe tools\route_check.py  :: какие фразы уходят в opencode
```

`warmup.py` проверяет CLI, версию opencode, загрузку Whisper, edge-tts, голоса
SAPI, микрофоны, выходы и `pygame`. `route_check.py` печатает решение роутера
для набора фраз — удобно, когда команда вдруг уходит в модель.

Лог: `logs\voicecode.log`.

### Если что-то не работает

| Симптом | Что делать |
| --- | --- |
| «Не нашёл opencode» | укажи путь в `opencode_cli`; проверь `opencode-cli --version` |
| «Не удалось загрузить модель Whisper» | собери модель (`tools\build_model.py`) или поставь `"whisper_model": "small"` |
| «Микрофон недоступен» | посмотри имя устройства в `warmup.py` и впиши его в `microphone` |
| `F8` не реагирует | закрой программы, перехватывающие клавишу; попробуй запуск от администратора; смени `global_hotkey` |
| Ответ есть, звука нет | проверь устройство вывода Windows; поставь `"tts_engine": "system"` |
| edge-tts молчит или ругается на сеть | это ожидаемо за прокси/файрволом — SAPI подхватится сам |
| «OpenCode's free tier can only be used from within OpenCode» | этот ответ возвращает сам opencode для сессионных флагов; VoiceCode их не использует — проверь версию CLI и аккаунт |
| Ответ приходит долго | уменьши `max_context_turns`, смени модель, включи `int8` и больше потоков |
| Окно не появляется | приложение уже в трее; второй экземпляр блокируется (`.lock` в `%TEMP%\voicecode`) |

## Ограничения

- Интерфейс и команды рассчитаны на русский язык и Windows.
- Ответ opencode нельзя прервать на стороне сервера: новая фраза отменяет
  воспроизведение и игнорирует опоздавший ответ, но процесс CLI доживает до
  таймаута.
- Озвучка читает только текст; markdown-разметка вычищается, но сложные ответы
  всё равно лучше просить коротко.
- Модель `small` иногда путает редкие имена программ — называй их чуть медленнее
  или добавь команду вручную в `voicecode/apps.py`.
